PORTFOLIO HANIF MAULANA FADHILA
=================================
Versi final HTML + CSS + JavaScript.

Cara pakai:
1. Extract folder.
2. Buka folder di VS Code.
3. Buka index.html dengan Live Server atau browser.
4. Masukkan foto kamu sebagai images/profile.jpg.
5. Ganti email, nomor HP, link sosial media, dan detail project di index.html.

Catatan:
Desain dibuat mengikuti mockup portofolio yang dibuat sebelumnya: layout, proporsi, warna, card, spacing, navbar, hero, skills, projects, experience, contact, footer, responsive, dan interaksi.
